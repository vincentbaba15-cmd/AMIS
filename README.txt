ALLOYD MONEK INTERNATIONAL SCHOOL WEBSITE

Files:
- index.html: React-powered responsive website using Tailwind CSS.
- assets/school-logo.png: extracted school crest, also used as favicon.
- assets/school-building.jpg, assets/students.jpg, assets/learning-space.jpg: photographs cropped from the supplied admission banner.

DEPLOY TO VERCEL (STATIC SITE)
1. Upload index.html and the complete assets folder to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Select Other as the framework preset if prompted.
4. Leave Build Command and Output Directory empty (or use the repository root as the output directory).
5. Deploy.

NOTES
- The site loads React and Tailwind from public CDNs, so an internet connection is required for those libraries and Google Fonts.
- All image references are relative paths under ./assets/; keep the assets folder beside index.html.
- The enquiry form opens WhatsApp with the visitor's message. The number is based on the banner contact number: 08036910106.
- The school promotion is shown as stated on the banner with a note to confirm current availability.
- No fees, academic results, facilities, email address, or unverified claims have been added.
